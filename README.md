# ООО «Возрождение» — сайт с PHP и базой данных

## Структура проекта

```
vozrozhdenie/
├── index.html          — главная страница (дизайн без изменений)
├── css/
│   └── style.css       — все стили (без изменений)
├── js/
│   └── main.js         — логика сайта (форма теперь идёт на api/submit.php)
├── api/
│   ├── config.php      — ВАШ ФАЙЛ: логин/пароль БД и почта для уведомлений
│   ├── database.php    — подключение к БД, создание таблицы, сохранение заявок
│   ├── submit.php      — принимает заявку от формы, сохраняет в БД, шлёт email
│   ├── admin.php       — панель просмотра всех заявок (с паролем)
│   └── logs/           — папка для логов (пустая, нужна структура)
└── uploads/            — для будущих файлов (пока не используется)
```

---

## Как запустить (пошагово)

### Шаг 1 — Загрузите файлы на хостинг
Скопируйте всю папку `vozrozhdenie/` в корень вашего сайта через FTP или файловый менеджер хостинга.

### Шаг 2 — Создайте базу данных
В панели хостинга (cPanel / ISPmanager) найдите раздел **«Базы данных MySQL»**:
1. Создайте новую базу данных, например `vozrozhdenie`
2. Создайте пользователя БД и придумайте пароль
3. Дайте пользователю **все права** на эту базу

### Шаг 3 — Заполните config.php
Откройте файл `api/config.php` и впишите данные из шага 2:
```php
define('DB_HOST', 'localhost');
define('DB_NAME', 'vozrozhdenie');   // имя базы
define('DB_USER', 'db_user');        // имя пользователя
define('DB_PASS', 'db_password');    // пароль
```

### Шаг 4 — Готово!
- Таблица `leads` создастся **автоматически** при первой заявке
- Заявки будут приходить на `vozrozhdenie4192@yandex.ru`

### Шаг 5 — Смените пароль администратора
В файле `api/admin.php` замените:
```php
$ADMIN_USER = 'admin';
$ADMIN_PASS = 'secret123';
```
На свои — иначе любой сможет просмотреть заявки.

---

## Как смотреть заявки

Откройте в браузере: `https://ваш-сайт.ru/api/admin.php`  
Введите логин и пароль администратора — увидите таблицу всех заявок.

---

## Что происходит при отправке заявки

1. Посетитель заполняет форму и нажимает «Отправить запрос»
2. JavaScript проверяет данные прямо в браузере
3. JavaScript отправляет данные на `api/submit.php`
4. PHP снова проверяет данные (на сервере)
5. PHP сохраняет заявку в таблицу `leads` в базе данных
6. PHP отправляет вам письмо на почту
7. Посетитель видит модальное окно «Заявка отправлена!»
